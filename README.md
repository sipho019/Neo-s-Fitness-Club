# Neo's Fitness Club

Welcome to Neo's Fitness Club official website. This is a responsive fitness website designed to help members explore gym services, view our gallery, and book training sessions online.

**Live Website:** https://sipho019.github.io/Neo-s-Fitness-Club/

### About The Project
This website was built as part of my Web Development POE. The goal was to create a professional, mobile-friendly website for a local fitness club using only HTML, CSS and JavaScript.

### Features
- Modern Home page with hero banner
- About Us section with trainer info
- Services page (Cardio, Strength Training, Yoga, Personal Training)
- Gallery page with gym images
- Online Booking Form
- Fully responsive on phone and desktop
- Clean and fast loading design

### Built With
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript
- GitHub Pages for hosting

### Folder Structure
- /HTML - All website pages
- /CSS - All styling files
- /MEDIA - All images and logos
- /JS - Booking form functionality

### How To Use
1. Clone this repo: git clone https://github.com/sipho019/Neo-s-Fitness-Club.git
2. Open HTML/index.html in your browser
